# Run narration yourself

Voice Studio uses local AI models to turn your text into speech. Chatterbox Turbo
provides the Natural narration engine; Whisper transcribes audiobook passages
for comparison with the source. Python coordinates workers, checkpoints, and
packaging. No Codex session is required to run it.

| Your goal | Start here |
| --- | --- |
| Set up a new computer | [Installation and first render](installation.md) |
| Preview and download spoken text | [Narrate text](narrating-text.md) |
| Turn an EPUB into chapter audio and M4B | [Create an audiobook](audiobooks.md) |
| Decide whether a flagged passage needs repair | [Review quality and export](quality-review.md) |
| Run unattended or diagnose a stop | [Background jobs and recovery](operations.md) |
| Control the already configured DDIA book | [Workstation runbook](workstation-ddia.md) |
| Look up paths, options, or commands | [Reference](reference.md) |

Generation and recognition stay on your computer. Installation downloads code and
models; the narration workflow does not upload your book or reference recording.
A **draft** includes flagged passages. **Verified** means the automated evidence
checks passed, not that every pronunciation sounds right. Listen to the result.
